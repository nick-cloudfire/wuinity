# Documentation folder

This folder holds supplementary and background material:

- `Wui_NITY architecture - inputs_outputs.pdf` – architecture overview.
- `workflow_new_file.docx` – notes on the scenario-building workflow.
- `new_input_format.wui` – **outdated.** This early draft uses key and section
  names the current engine no longer reads.

> For the current, authoritative documentation see the **[`docs/`](../docs/)**
> folder. In particular, the `.wui` file format is documented in
> [`docs/input-file-format.md`](../docs/input-file-format.md), which is generated
> from the actual parser and supersedes `new_input_format.wui`.
